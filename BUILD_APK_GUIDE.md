# Building APK Locally (Without EAS Build)

This guide will help you build an APK file locally from your Expo project without using EAS Build or Expo Go.

## Prerequisites

Before building, make sure you have the following installed:

1. **Node.js** (v18 or higher recommended)
   - Download from: https://nodejs.org/
   - Verify: `node --version`

2. **Java JDK** (JDK 17 or higher)
   - Download from: https://adoptium.net/ or https://www.oracle.com/java/technologies/downloads/
   - Verify: `java -version`
   - Set `JAVA_HOME` environment variable to your JDK installation path

3. **Android Studio** (for Android SDK)
   - Download from: https://developer.android.com/studio
   - Install Android SDK (API level 35 as per your config)
   - Set `ANDROID_HOME` environment variable:
     - Windows: `C:\Users\YourUsername\AppData\Local\Android\Sdk`
   - Add to PATH:
     - `%ANDROID_HOME%\platform-tools`
     - `%ANDROID_HOME%\tools`
     - `%ANDROID_HOME%\tools\bin`

4. **Expo CLI** (should be installed via npm)
   - Verify: `npx expo --version`

## Building the APK

### Method 1: Using the Batch Script (Recommended for Windows)

Simply double-click `build-apk.bat` or run it from the command line:

```bash
build-apk.bat
```

The script will:
1. Check if Android native code exists (if not, run prebuild)
2. Clean previous builds
3. Build the release APK using Gradle
4. Show you the APK location when complete

### Method 2: Using npm Script

```bash
npm run build:android
```

### Method 3: Manual Steps

If you prefer to run the steps manually:

1. **Generate Android native code** (if not already done):
   ```bash
   npx expo prebuild --platform android --clean
   ```

2. **Build the APK**:
   ```bash
   cd android
   gradlew.bat assembleRelease
   cd ..
   ```

3. **Find your APK**:
   The APK will be located at:
   ```
   android\app\build\outputs\apk\release\app-release.apk
   ```

## What Happens During Build

1. **Prebuild**: Expo generates the native Android project from your `app.json` configuration
2. **Gradle Build**: Android's build system compiles your app into an APK
3. **Output**: A release APK ready for installation

## Installing the APK

1. Transfer the APK file to your Android device (via USB, email, cloud storage, etc.)
2. On your Android device, enable "Install from Unknown Sources":
   - Go to Settings → Security → Enable "Unknown Sources" or
   - Go to Settings → Apps → Special Access → Install Unknown Apps
3. Open the APK file on your device and tap "Install"

## Troubleshooting

### Error: "Android SDK not found"
- Make sure Android Studio is installed
- Set `ANDROID_HOME` environment variable correctly
- Verify SDK is installed: Open Android Studio → SDK Manager

### Error: "Java not found"
- Install JDK 17 or higher
- Set `JAVA_HOME` environment variable
- Add Java to your PATH

### Error: "Gradle build failed"
- Check that all dependencies are installed: `npm install`
- Make sure you have enough disk space
- Try cleaning the build: Delete `android` folder and run prebuild again

### Error: "Prebuild failed"
- Check your `app.json` for syntax errors
- Make sure all required assets exist (icons, splash screens)
- Verify all plugins in `app.json` are compatible with Expo SDK 54

### Build takes too long
- First build always takes longer (downloading dependencies)
- Subsequent builds will be faster
- Make sure you have a stable internet connection

## Notes

- The `android` folder is generated by Expo and can be deleted/recreated anytime
- The APK is unsigned (for testing). To publish to Play Store, you'll need to sign it
- This builds a standalone APK, not an Expo Go app
- The build process may take 5-15 minutes depending on your system

## Signing the APK (Optional, for Play Store)

If you want to publish to Google Play Store, you'll need to sign the APK:

1. Generate a keystore:
   ```bash
   keytool -genkeypair -v -storetype PKCS12 -keystore my-release-key.keystore -alias my-key-alias -keyalg RSA -keysize 2048 -validity 10000
   ```

2. Configure signing in `android/app/build.gradle` (after prebuild)

3. Build signed APK:
   ```bash
   cd android
   gradlew.bat assembleRelease
   ```

For more details on signing, see: https://reactnative.dev/docs/signed-apk-android
